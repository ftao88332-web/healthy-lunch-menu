# 地中海健康午餐 · 网页版（无 Key 完整版）

这是一个**打包产物**，由 `后端/tools/make_public_bundle.js --nokey` 生成，请勿直接手改。

## 和源码版的区别

| 项目 | 源码版 `网页版/` | 本版 |
| --- | --- | --- |
| 功能 | 完整 | **完整**（生成 / 换食材 / 换一道 / 配图都在） |
| API Key | 内置在页面里 | **已移除** |
| 内置菜单 | 有 | 有（打开即看，不需要 Key） |

## 访客怎么用

1. **只是看菜单**：直接打开就行，内置的预生成菜谱照常显示，不需要任何配置。
2. **想自己生成**：右上角「设置」→ 填自己的智谱 API Key → 保存。
   Key 存在浏览器本地，不会上传到任何地方。

智谱 Key 在 <https://open.bigmodel.cn> 注册后免费申请。

## 为什么要留空

这一版是给**公开仓库 / 公开站点**用的 —— 源码对全世界可见，
内置 Key 等于把额度送出去。留空之后：功能一个不少，但风险归零。

## 想让访客零配置直接用怎么办

那就得内置 Key（用源码版 `网页版/index.html`），或者接自己的后端
（`--backend https://…`，见 `部署到微信云托管.md`）。
