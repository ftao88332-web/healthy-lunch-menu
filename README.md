# 地中海健康午餐 · 网页版（混淆 Key 版）

这是一个**打包产物**，由 `后端/tools/make_public_bundle.js --obf` 生成。

## 这版是什么

功能完整（生成菜单 / 换食材 / 换一道 / AI 配图 / 采购清单都在），
并且**内置了 API Key，任何人打开就能直接用，不需要任何配置**。

Key 在源码里是**混淆态**（XOR + base64，带 `OBF1:` 前缀），
不是明文 —— 这样源码能公开，也不会被 GitHub secret scanning 扫到。

## ⚠️ 混淆 ≠ 加密，别误会

静态页面里的 Key **做不到真正加密**：浏览器必须能还原出明文才能发请求，
所以解码逻辑必然也在页面里。

| 能挡住 | 挡不住 |
| --- | --- |
| GitHub 等平台的 secret scanning（明文 Key 推公开仓库可能被服务商自动吊销） | 懂技术的人打开 F12 看 Network 面板里的 `Authorization` 头 |
| 直接在源码里搜 Key 字符串的复制粘贴党 | 照着解码函数跑一遍 |

所以这一版适合**公开给大家用**，但请务必：
- 保持智谱账户**余额低位**（官方不支持退款）
- 常看「财务总览」；发现异常立刻**删 Key**（删除后即时失效、不再扣费）

真正要 Key 安全，只能走后端模式（`--backend https://…`）。

## 重新打包

```bash
cd 后端
node tools/make_public_bundle.js --obf
```

明文 Key 从 `网页版/index.html` 的 `DEFAULT_KEY` 读取，
**不会出现在命令行里**（避免留在 shell 历史）。
